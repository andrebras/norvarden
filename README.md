# Norvarden

The company website and custom vector identity for **Norvarden**, an independent software engineering company. Live at **https://www.norvarden.com**.

## Development

Install **Node.js 20 or newer** (CI uses Node 22). There is no database and no environment variables. The only build step is `npm run build`, which `npm run dev`, `npm start` and `npm test` run for you.

```sh
git clone git@github.com:andrebras/norvarden.git
cd norvarden
npm ci
npm run dev
```

`npm run dev` builds the site, then serves `dist/` at **http://localhost:8000**. To change the port, run `PORT=8080 npm run dev`.

```sh
npm run build    # bundle src/monitoring.js into dist/monitoring.js
npm run format   # format HTML, CSS, JS, and Markdown with Prettier
npm run lint     # Prettier check, html-validate, Stylelint and ESLint
npm test         # build, lint and run the site checks
```

`npm test` builds, runs the linters, then runs `scripts/check.mjs`. The checks cover duplicate IDs, local asset references, anchor targets, form labels, reduced-motion support, no third-party scripts, mobile menu behaviour, service selection, email encoding, and copying the enquiry draft. They do not replace a real desktop/mobile browser review.

CI (`.github/workflows/ci.yml`) runs `npm ci` and `npm test` on Node 22 for every pull request and push to `main`.

## Monitoring

AppSignal (Norvarden organization) watches the site:

- **Uptime:** `https://www.norvarden.com` is checked every minute from four regions (Europe, North America, Asia-Pacific and South America), with a 2-minute warmup and email alerts. The check also confirms the page contains "Software with a future".
- **Status page:** the public status page is **https://status.norvarden.com**.
- **Front-end errors:** `src/monitoring.js` reports uncaught JavaScript errors. `npm run build` (`scripts/build.mjs`, using esbuild) bundles it into `dist/monitoring.js`, tagged with the commit SHA as the revision. The bundle is not committed; the Pages workflow builds it. It only reports on `www.norvarden.com`, sends no form contents, and uses AppSignal's public front-end key.

## Structure

- `src/monitoring.js` — AppSignal front-end error reporting source.
- `dist/index.html` — complete homepage, content, and metadata.
- `dist/styles.css` — responsive visual system, including reduced-motion support.
- `dist/app.js` — accessible mobile navigation and email brief preparation.
- `dist/monitoring.js` — generated by `npm run build`; not committed.
- `dist/404.html` — not-found page.
- `dist/robots.txt`, `dist/sitemap.xml` — crawler instructions and sitemap.
- `dist/CNAME` — custom domain for GitHub Pages.
- `dist/assets/logo.svg` — custom path-based Norvarden wordmark and N symbol; no font dependency.
- `dist/assets/symbol.svg` — transparent standalone N symbol.
- `dist/assets/logo-light.svg` — reversed wordmark for dark backgrounds.
- `dist/assets/mark.svg` — square favicon.
- `dist/assets/apple-touch-icon.png` — home-screen icon.
- `dist/assets/social.png` — 1200×630 social sharing image.
- `dist/assets/social.svg` — editable social artwork concept.
- `scripts/build.mjs` — bundles `src/monitoring.js` into `dist/monitoring.js`.
- `scripts/serve.mjs` — dependency-free local server for `dist/`.
- `scripts/check.mjs` — site checks.
- `.github/workflows/ci.yml`, `.github/workflows/pages.yml` — CI and deployment.

Latest projects uses a typographic presentation without thumbnail illustrations. Plymico is marked free, BetweenStays links to betweenstays.eu, and DriveDeck is marked coming soon.

## Hosting

The site is hosted on **GitHub Pages**. `.github/workflows/pages.yml` runs on every push to `main` (or manually): it runs `npm test`, then runs `npm run build` and publishes `dist/`. Every other file in `dist/` is committed as it is served.

- **Domain:** `www.norvarden.com` is the canonical address; `norvarden.com` redirects to it.
- **DNS (Namecheap):** four `A` records for `@` pointing to GitHub Pages (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`) and a `CNAME` record for `www` pointing to `andrebras.github.io`.

## Contact

The site uses **hello@norvarden.com**. Mail to it is delivered through Namecheap email forwarding to a personal inbox. This is forwarding only: there is no mailbox, so replies are sent from the receiving address.

The contact form prepares an email in the visitor's own email app. It does **not** send mail, store enquiries, or claim that an enquiry was delivered. A copy-draft option is provided if the email app does not open. No analytics or cookies are included; AppSignal error reporting is the only outside connection.

## Identity

- Ink: `#1b211c`

- Signal green: `#d7f46a`

The Waymark is formed by three ascending angular planes. The hero uses an offset outline and diagonal hatching, while the small logo stays clean. The wordmark uses custom SVG paths. System sans-serif typography and an editorial serif accent keep the site self-contained.
